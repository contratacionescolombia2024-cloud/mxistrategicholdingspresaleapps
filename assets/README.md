# Assets Directory

This directory contains image assets for the Expo application.

## Required Assets

You should add the following image files to this directory:

- **icon.png** - App icon (1024x1024 px recommended)
- **splash.png** - Splash screen image (1284x2778 px for iOS, adjust as needed)
- **adaptive-icon.png** - Android adaptive icon (1024x1024 px)
- **favicon.png** - Web favicon (48x48 px or larger)

## Creating Assets

You can use online tools like:
- https://appicon.co/ - Generate app icons from a single image
- https://expo.dev/tools - Expo's asset generation tools

Or create them manually using design tools like Figma, Photoshop, or GIMP.
